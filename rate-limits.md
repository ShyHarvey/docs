# Лимиты запросов

Чтобы API оставался стабильным, количество запросов ограничено для каждого
API-ключа.

| Тариф | Запросов в минуту |
| --- | ---: |
| Demo | 60 |
| Pro | 1 000 |

## Заголовки ответа

Каждый ответ содержит информацию о текущем лимите:

```http
X-RateLimit-Limit: 60
X-RateLimit-Remaining: 42
X-RateLimit-Reset: 1791885600
```

- `X-RateLimit-Limit` — максимальное число запросов в окне.
- `X-RateLimit-Remaining` — сколько запросов осталось.
- `X-RateLimit-Reset` — время сброса лимита в формате Unix timestamp.

## Превышение лимита

Если лимит исчерпан, API вернёт статус `429 Too Many Requests`:

```json
{
  "error": {
    "code": "rate_limit_exceeded",
    "message": "Слишком много запросов. Повторите попытку через 15 секунд."
  }
}
```

Заголовок `Retry-After` подскажет, сколько секунд нужно подождать:

```http
Retry-After: 15
```

<Tip>
  Кэшируйте ответы и объединяйте операции, чтобы не расходовать лимит на
  одинаковые запросы.
</Tip>
