# Ошибки API

Tiny Tasks API использует стандартные HTTP-коды состояния. Ответ с ошибкой
всегда приходит в формате JSON.

## Формат ответа

```json
{
  "error": {
    "code": "invalid_request",
    "message": "Поле title обязательно",
    "requestId": "req_01J9ZQ2K8M"
  }
}
```

## Коды состояния

| Код | Значение | Что делать |
| --- | --- | --- |
| `400` | Некорректный запрос | Проверьте тело запроса и обязательные поля |
| `401` | Ошибка авторизации | Проверьте API-ключ в заголовке `Authorization` |
| `404` | Ресурс не найден | Проверьте идентификатор задачи |
| `429` | Слишком много запросов | Повторите запрос с задержкой |
| `500` | Внутренняя ошибка | Повторите запрос позднее |

## Повтор запросов

При ответах `429` и `500` используйте экспоненциальную задержку:

```javascript
const delay = (attempt) => Math.min(1000 * 2 ** attempt, 30_000);
```

Не повторяйте автоматически запросы с кодами `400`, `401` и `404`: сначала
нужно исправить сам запрос.

> При обращении в поддержку передайте значение `requestId` — оно поможет найти
> запрос в логах.
